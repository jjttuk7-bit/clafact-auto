# 공식 근거 출처 표시 설계

## 목적

최종 판정에 사용한 값이 KOSIS 공식값 API에서 왔는지, 관세청 등 공식 작성기관 문서에서 왔는지를 대시보드와 검토 데이터에 정확하게 표시한다.

## 출처 판별 규칙

1. 공식 근거 좌표(`evidence_cells`)가 있으면 `KOSIS 공식값`으로 표시한다.
2. 공식 근거 좌표가 없고 값 근거가 `OFFICIAL_DOCUMENT`이면 `공식 작성기관 문서값`으로 표시한다.
3. 두 근거가 함께 있으면 값 좌표가 존재하는 KOSIS를 값 출처로 우선 표시하고, 공식 문서는 공표 근거로 보존한다.
4. 어느 쪽도 확정할 수 없으면 `공식값`으로 표시한다.

## 반영 범위

- 대시보드 상단 안내 문구
- 자동 판정 성공 메시지와 최종값 지표 제목
- 규칙 기반 및 AI 자연어 설명의 고정 사실
- 공식 작성기관 문서 URL·조회시각·응답 해시 표시
- 검토 콘솔의 근거 개수
- 3갈래 실행 추적의 `어떤 데이터`에 공식 작성기관 검색·문서 조회 단계 포함

## 근거 개수

KOSIS 좌표 수와 공식값 출처 기록 수 중 큰 값을 사용한다. 동일한 KOSIS 값을 좌표와 출처 기록으로 두 번 세지 않으면서, 좌표 없이 공식 문서만 사용한 경우도 1건으로 기록한다.

## 완료 기준

- 관세청 공식 문서 판정은 `공식 작성기관 문서값`으로 표시된다.
- KOSIS API 판정은 기존처럼 `KOSIS 공식값`으로 표시된다.
- 공식 문서 판정의 검토 데이터 `evidence_count`가 1 이상이다.
- `OFFICIAL_AUTHOR_SEARCH`, `OFFICIAL_AUTHOR_FETCH`가 `어떤 데이터`에 나타난다.
- 전체 테스트와 실제 대표 Claim 대시보드 경로가 통과한다.
