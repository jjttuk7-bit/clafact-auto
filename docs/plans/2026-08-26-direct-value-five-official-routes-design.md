# 8번 직접값 5개 공식 경로 규칙 설계

## 목표

이미 공식 근거까지 완료된 직접값 Claim 10건에서 반복 가능한 공식 경로 5개를 추출해 등록하고, 같은 경로를 써야 하지만 미해결인 Claim 7건만 재실행한다. 결과는 기존 완료 10건에서 몇 건으로 늘었는지 전후 CSV로 감사 가능하게 남긴다.

## 적용 범위

1. 관세청 무역수지 누계 공식 보도자료
2. 월간 전국 전체 취업자 수 — KOSIS `DT_1DA7001S`, 항목 `T30`
3. 월간 전국 전체 실업률 — KOSIS `DT_1DA7001S`, 항목 `T80`
4. 월간 연령별 고용률 — KOSIS `DT_1DA7002S`, 항목 `T90`
5. 분기 연령·학력별 실업률 — KOSIS `DT_1DA7105S`, 항목 `T80`

특정 Claim ID나 기사 문장을 규칙에 넣지 않는다. 표·항목 규칙은 실제 KOSIS 카탈로그 검색 및 구조정보 조회 결과 안에 동일한 공식 좌표가 있을 때만 후보를 좁힌다. 관세청 문서도 기존 공식 작성기관 검색·문서 추출 경로를 그대로 사용한다.

## 미해결 7건의 공통 원인

- 월간 전체 취업자 3건: `15세 이상`이 표 자체의 모집단 범위인데 별도 차원 코드가 필요한 값으로 취급되어 좌표 확정에 실패한다.
- 월간 연령별 고용률 2건: 같은 개념의 표가 여러 개 검색되어 연령별 공식표를 안정적으로 선택하지 못한다.
- 분기 연령·학력별 실업률 2건: 복수 수치 문장에서 대상 수치의 연령·학력 범위가 자식 Claim에 완전하게 보존되지 않거나, 해당 공식표를 하나로 좁히지 못한다.

## 구현 원칙

- 등록 규칙은 개념·주기·지역 범위·연령/학력 축 존재 여부로 적용한다.
- 표 자체 범위인 `15세 이상 전체`는 바인딩의 범위 정보로 보존하여 별도 차원 누락으로 오판하지 않는다.
- 연령·학력 값은 고정 코드를 넣지 않고 공식 구조정보의 차원 멤버에서 동적으로 찾는다.
- 원문에 정확히 존재하는 목표 수치만 복구한다. 복수 수치가 모호하면 계속 보류한다.
- 공식 판정 완료는 근거 셀, 실제 API/공식문서 출처, URL, 응답 해시, 조회 시각, 공표 확인이 모두 있는 경우만 센다.

## 완료 기준

- 5개 경로에 대한 단위 테스트와 안전 음성 테스트 통과
- 미해결 7건의 구현 전·후 결과를 동일한 실행 경로로 저장
- 7건 각각의 이전 실패 단계, 이후 결과, 공식표/항목/차원, 공식값, 출처 URL, 응답 해시를 CSV에 기록
- 기존 10건 + 신규 해결 건수 = 최종 누적 완료 건수를 명시
