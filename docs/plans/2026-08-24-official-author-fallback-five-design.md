# 공식 작성기관 보조 경로 5건 설계

## 목표

`KOSIS_CATALOG_UNAVAILABLE`로 끝난 대표 자식 Claim 5건만 다시 실행한다. KOSIS를 먼저 실제 조회하고, 실패했을 때에만 공식 작성기관 자료를 조회하여 기존 실패를 정확한 판정 또는 정확한 보류 사유로 바꾼다.

## 선택한 방식

검색어만 늘리거나 Claim ID별 결과를 고정하지 않는다. 지표 별칭, 작성기관, 신뢰 도메인, 공식 검색/자료 경로, 값 추출 규칙을 등록하는 재사용 가능한 프로필을 둔다. 공식 문서는 실행 시 직접 내려받고 원문에서 기간·값·단위를 추출한다.

## 처리 흐름

1. 기존 v3 엔진으로 KOSIS 검색을 먼저 실행한다.
2. 결과가 `KOSIS_CATALOG_UNAVAILABLE`일 때만 작성기관 보조 경로를 연다.
3. Claim의 지표·기관 힌트·대상·지역으로 하나의 프로필을 선택한다. 모호하면 강제 선택하지 않는다.
4. 공식 자료를 직접 조회하고 URL, 조회 시각, 응답 SHA-256 해시를 저장한다.
5. 자료의 게시일이 기사일 이하인지 확인한다.
6. 자료에서 대상 기간과 수치·단위를 추출하고 Python으로 Claim 값과 비교한다.
7. 성공은 `MATCH/MISMATCH`, 자료가 기사보다 늦으면 `AS_OF_UNAVAILABLE`, 공식 자료를 찾지 못하거나 모호하면 작성기관 근거 미확보 HOLD로 기록한다.

## 대상 범위

- 한국소비자원 생필품 가격: 평균 상승폭 3.9%
- 국토교통부/해외건설 실적: 누적 수주 1조 달러
- 농림축산식품부 농식품 수출: 미국 라면 수출 증가율 70.3%
- 현대자동차그룹: 현대차·기아 전체 수출 2,180,698대
- 현대자동차그룹: 미국 대통령 취임식 기금 100만 달러

## 안전장치

- 특정 Claim ID나 기사 문장으로 성공값을 반환하지 않는다.
- 허용된 공식 도메인 밖의 문서는 거부한다.
- 기간·대상·단위 가운데 하나라도 확인되지 않으면 자동 판정하지 않는다.
- 공식값과 계산은 LLM이 만들지 않는다.
- 실제 공식 요청이 없으면 완료로 집계하지 않는다.
- 5건만 실행하며 1,542건 전체 실행은 금지한다.
