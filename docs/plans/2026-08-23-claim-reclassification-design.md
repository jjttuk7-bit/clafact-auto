# Claim 재분류 설계

## 목적

CONTEXT 묶음에서 공식 통계 검증 대상, 미래 예측·정책 계획, 검증할 수치가 없는 문장, 원문 근거 부족을 구분한다. 재분류 완료를 KOSIS 검증 성공으로 계산하지 않으면서도, 올바르게 제외된 Claim이 영구 실패로 남지 않게 한다.

## 분류

| 분류 | 의미 | 다음 경로 |
| --- | --- | --- |
| `OFFICIAL_VERIFICATION_TARGET` | 공식 통계로 검증할 수 있는 사실형 수치 Claim | 공식 통계 검색 |
| `FORECAST_OR_POLICY` | 전망·예상·계획·방침 등 아직 발생하지 않은 내용 | 검증 전 제외 |
| `NO_VERIFIABLE_NUMERIC_ASSERTION` | 지표값·증감값 등 검증할 수치 주장이 없음 | 검증 전 제외 |
| `SOURCE_CONTEXT_INSUFFICIENT` | 수치 주장은 있으나 시점·비교 등 원문 근거가 부족함 | 문맥 보강 또는 사람 확인 |

기업·협회 통계처럼 KOSIS 외 공식기관이 필요한 사실형 Claim은 제외하지 않는다. 이 단계에서는 `OFFICIAL_VERIFICATION_TARGET`으로 보존하고, 후속 official engine이 KOSIS-first 뒤 공식 작성기관 보조경로를 선택한다.

## 판정 원칙

- 특정 Claim ID나 특정 문장으로 분류하지 않는다.
- 전망·계획은 명시적인 표현이 있을 때만 제외한다.
- 숫자로 보이는 연도·순위만 있고 검증할 지표값이 없으면 수치 Claim 아님으로 분류한다.
- 애매하면 제외하지 않고 `SOURCE_CONTEXT_INSUFFICIENT`로 남긴다.
- 재분류는 공식 API 성공이 아니며, CSV에서 별도 수치로 집계한다.

## 데이터 흐름

```text
Claim 분리 및 12개 항목 추출
→ Claim 성격 판정
  → 공식 검증 대상: 기존 공식 조회 입장
  → 전망·계획: 검증 전 제외
  → 수치 주장 아님: 검증 전 제외
  → 원문 부족: 미완료 유지
→ 부모 Claim 결과 합산
→ 자식/부모 CSV 기록
→ 묶음 진행표에 공식조회진입수와 재분류완료수를 분리 집계
```

## 부모 Claim 완료 규칙

- 모든 자식이 공식 조회 가능하면 `PASS`.
- 모든 자식이 안전한 제외 분류이면 `RECLASSIFIED`.
- 공식 조회 가능 자식과 안전한 제외 자식만 섞여 있으면 `PASS`이며 재분류 수를 함께 기록한다.
- 하나라도 원문 부족 또는 구조 미완성이면 `HUMAN_REVIEW`를 유지한다.

## CSV 변경

부모 실행 CSV와 자식 12개 항목 CSV에 다음 열을 추가한다.

- `재분류결과`
- `재분류사유`
- `다음경로`

묶음 진행표에는 다음 숫자를 분리한다.

- `공식조회진입수`
- `재분류완료수`
- `남은수`

## 검증

- 전망/계획을 제외하는 단위 테스트
- 사실형 수치 Claim을 잘못 제외하지 않는 보호 테스트
- 수치 주장이 없는 문장 분류 테스트
- 혼합 자식 부모의 완료 판정 테스트
- CSV 열과 집계 테스트
- 같은 CONTEXT 첫 20건 저장 결과 재평가
- 새로운 전체 1,542건 실행과 KOSIS 호출은 금지
