# 직접값 381건 숫자 역할 분류 설계

## 목적

원문 수치 목록 1,456개 각각에 역할 또는 자동 대상 제외 이유를 기록한다. 저장된 기사값을 그대로 신뢰하지 않고 원문 표현·단위·문법과 대조하여 `20대`, `5개월`, `상위 7개` 같은 맥락 숫자가 대상값으로 승인되지 않게 한다.

## 선택한 방식

- 외부 LLM 전량 분류는 외부 전송 승인과 재현성 검증 문제가 있어 사용하지 않는다.
- 규칙으로 하나의 대상값을 강제하지 않는다.
- 결정론적 고신뢰 역할 분류 후 애매한 값은 `자동대상제외`와 구체적 이유로 보존한다.

## 역할

- `대상값`: 저장 기사값·단위와 원문 표현이 일치하고 변화 문법이 아닌 값
- `증감값`: 저장 기사값과 일치하며 증가·감소·상승·하락 문법에 연결된 값
- `비교값`: 이전·당초·비교 기준으로 제시된 값
- `환산값`: 괄호 안 한화 환산 등 같은 사실의 다른 단위 값
- `기간`, `기준연도`, `기준값`, `연령`, `순위`: 검증 조건을 나타내는 숫자
- `맥락값`: 통계값이지만 현재 Claim의 자동 대상이 아닌 값
- `제외`: 모델명·깨진 원문·서수 등 통계 검증에 직접 쓰지 않는 값

## 분류 우선순위

1. 잘린 표현·제품 모델·서수는 제외한다.
2. 기준연도·기준값·연령·순위·기간을 먼저 확정한다.
3. 괄호 속 다른 통화 환산값을 판별한다.
4. 저장 기사값·단위를 원문 수치로 환산해 일치 후보를 찾는다.
5. 증가·감소 문법이면 증감값, 아니면 대상값으로 분류한다.
6. 후보가 없거나 여러 개면 강제 선택하지 않고 자동 대상에서 제외한다.

## 완료 조건

- Claim 381건, 수치 역할 1,456개
- 역할 미지정 0개
- 자동 대상이 아닌 수치의 제외 이유 누락 0개
- 연령·기간·순위가 대상값으로 통과한 충돌 0개
- 원문 위치·숫자 목록 계수 불일치 0개
