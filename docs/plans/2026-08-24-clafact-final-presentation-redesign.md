# CLAFACT-AUTO 최종 발표자료 재구성 설계

## 목표

2026-08-18 발표자료의 디자인과 핵심 원칙을 유지하면서, 2026-08-24 현재까지 구현된 복합 Claim 재분류·재투입, 기사 시점 값 보호, 문제 유형별 개선 하네스, 통합 진행 원장, 최신 남은 문제 분포를 반영한 22장 발표자료를 만든다.

## 구성 원칙

1. 원본 PPTX는 변경하지 않고 새 파일을 만든다.
2. 기존의 청록·남색·연노랑 색상, 카드형 레이아웃, 큰 수치 강조 방식을 유지한다.
3. 발표 흐름은 `문제 → 원칙 → 파이프라인 → 실제 사례 → 평가 → 현재 상태 → 완료 계획` 순서를 유지한다.
4. 영어가 필요한 경우 한글 설명을 함께 제시한다.
5. 현재 완료 24건을 자동 판정 24건으로 표현하지 않는다.
6. 최신 전체 실행 기준선과 유형별 개선이 반영된 통합 진행 원장을 구분한다.
7. 모든 수치는 2026-08-24 통합 진행 원장과 실행 보고서를 근거로 한다.
