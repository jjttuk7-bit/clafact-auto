# 1,542건 통합 진행 원장 설계

## 목적

분산된 문제 묶음 실행 결과를 하나의 `CLAFACT_1542_통합진행원장.csv`로 합친다. 이후 새 묶음 결과가 생겨도 같은 명령을 다시 실행하면 최신 원장이 재생성되어 남은 작업 수를 정확히 계산할 수 있어야 한다.

## 기준 단위

원장의 한 행은 고정된 원본 Claim 한 건이다. 따라서 출력은 항상 1,542행이며 `기사번호 + 문장번호 + 부모Claim번호 + Claim번호`가 중복되지 않는다. 여러 자식 Claim은 새 행으로 늘리지 않고 부모 행의 자식 결과 열에 묶어서 기록한다.

## 병합 방식

기존 원장을 직접 덧붙여 수정하지 않는다. 매번 다음 입력으로 새 파일을 원자적으로 재생성한다.

1. 고정된 1,542행 문제 원장
2. 하네스 실행 결과 CSV
3. 기록 비교 실행 CSV
4. 다중 Claim 분리 결과 CSV
5. 공식 단계 결과 CSV
6. 묶음 완료 판정 CSV
7. 자식 Claim을 부모 Claim으로 연결하는 Registry JSONL

각 결과는 파일 수정 시각 또는 명시된 실행 시각으로 정렬한다. 같은 Claim에는 최신 결과를 현재 결과로 반영하고, 전체 이력 수와 사용한 결과 파일을 함께 기록한다.

## 안전 규칙

- 원본 1,542행과 식별자는 변경하지 않는다.
- 알 수 없는 부모 Claim 결과는 자동으로 버리지 않고 생성 오류로 처리한다.
- 동일한 Claim·동일한 시각에 서로 다른 결과가 있으면 생성 오류로 처리한다.
- 자식 일부만 성공한 부모를 전체 성공으로 만들지 않는다.
- 공식 조회 여부는 결과 CSV에 공식 API 근거가 명시된 경우에만 `예`로 기록한다.
- 결과가 없는 Claim은 기존 문제와 다음 작업을 그대로 유지한다.

## 추가 기록 열

- 최신결과상태·단계·사유
- 최신개선판정
- 최신자식Claim번호
- 최신공식조회여부·통계표·좌표·공식값·계산값·판정·공표확인
- 최신결과출처·실행번호·기록시각
- 반영된 결과 수
- 남은작업

## 완료 조건

- 출력 행 수 1,542
- 식별자 중복·누락 0
- 인식한 모든 결과가 원장의 부모 Claim에 연결됨
- 최근 고용 증감액 4건과 기록 비교 대표 결과가 반영됨
- 같은 입력으로 다시 만들면 내용이 동일함
- 통합 결과 요약에 반영 Claim 수와 문제 묶음별 남은 수가 기록됨
