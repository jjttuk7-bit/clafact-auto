# 고용 증감액 문맥 비교 기준 복원 설계

## 목적

대상 문장에는 `37만명 늘었다`, `13만2000명 늘었다`처럼 증감액만 있고 비교 기준이 생략되어 있다. 같은 기사의 앞 문장에서 비교 기준이 명확하고 하나로 일치할 때만 `현재 공식값 - 비교 시점 공식값` Claim으로 재분류한다.

이번 실행 대상은 다음 2건뿐이다.

- `claim_51187645801dea7d`: 60세 이상 취업자 37만명 증가
- `claim_60c76d3e7237ece9`: 30대 취업자 13만2000명 증가

## 안전 규칙

1. 대상 문장 자체의 수치와 증가·감소 표현이 먼저 확인되어야 한다.
2. 같은 기사에서 대상 문장보다 앞선 문장만 문맥으로 사용한다.
3. 앞 문맥에 명시된 비교 기준이 정확히 한 종류일 때만 사용한다.
4. `전년 동월 대비`와 `전월 대비`처럼 기준이 섞이면 자동 복원하지 않는다.
5. 문맥이 없거나 기준이 모호하면 기존 Claim을 유지하며 공식 판정을 강제하지 않는다.
6. Claim ID나 특정 기사 문장을 운영 코드에 고정하지 않는다.

## 데이터 흐름

```text
명시적으로 선택한 Claim 2건
→ 같은 기사 앞 문장 수집
→ 비교 표현을 표준 비교 기준으로 변환
→ 단일 기준 여부 확인
→ 증감액 Claim을 두 시점 차이 계산으로 재분류
→ 기존 공식 KOSIS 파이프라인
→ 현재·비교 시점 공식값 조회
→ Python 차이 계산
→ 판정 및 CSV 기록
```

## 기록

재분류 결과에는 사용한 비교 기준, 문맥 문장 번호와 문장을 남긴다. 공식 실행 결과에는 두 공식값의 좌표, 출처 URL, 조회 시각, 응답 해시, 공표 근거, Python 계산값과 최종 판정을 남긴다.

## 완료 조건

- 문맥 기준이 하나인 테스트는 두 시점 차이 계산으로 재분류된다.
- 비교 기준이 충돌하거나 다른 기사 문맥인 테스트는 재분류되지 않는다.
- 선택한 2건 외 Claim은 읽거나 실행 범위를 넓히지 않는다.
- 두 Claim 각각 실제 공식 API 실행 결과와 CSV 감사 기록이 생성된다.
