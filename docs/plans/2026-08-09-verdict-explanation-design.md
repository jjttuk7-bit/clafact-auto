# 판정 설명 분리 설계

## 목적

결론은 KOSIS 공식값과 Python 계산만으로 `일치`, `불일치`, `판정 불가` 중 하나로 확정하고, LLM은 확정 결과를 사용자가 이해하기 쉬운 한국어로 풀어 쓰는 역할만 맡는다.

## 경계

- `VerdictSchema`의 `verdict`, `route_status`, 공식값과 근거 좌표는 LLM이 변경할 수 없다.
- 설명 입력은 이미 확정된 Verdict의 제한된 사본이다.
- LLM은 strict Function Calling Structured Output으로 짧은 설명만 반환한다.
- 설명 호출 실패·계약 위반·인증 오류는 판정을 보류시키지 않으며, 규칙 기반 한국어 설명으로 대체한다.
- 숫자·날짜·KOSIS 표 ID는 결정론적 렌더러만 표시한다.

## 사용자 화면

최종 판정 아래에 `판정 설명`을 표시한다. `설명 방식`은 `AI 자연어 설명` 또는 `규칙 기반 설명`으로 명시한다. 내부 JSON과 감사 코드값은 기존대로 보존한다.
