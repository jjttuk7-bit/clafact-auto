CLAFACT-AUTO 주장 구간별 성능 개선 상세 기획

작성일: 2026-08-22


1. 이 기획의 목적

지금까지는 1,542개 주장을 한꺼번에 실행한 뒤 전체 성공·실패 수를 확인했다.
이 방식은 현재 상태를 파악하는 데는 도움이 됐지만, 서로 다른 문제가 한 실행에 섞여 다음과 같은 어려움이 생겼다.

- 어느 문제를 고쳐서 결과가 좋아졌는지 알기 어렵다.
- 이미 성공한 주장도 불필요하게 다시 조회한다.
- 국가통계포털 조회가 약 2만 5천 회 발생한다.
- 외부 조회 장애와 프로그램의 판단 실패가 섞인다.
- 한 구간을 고친 뒤 다시 1,542개 전체를 돌려야 해 시간과 조회량이 커진다.

앞으로는 모든 문제 주장을 처음 멈춘 구간 하나에만 배정한다.
각 구간 안에서 고용·출산·물가·산업 등 분야별로 다시 나누고, 20건 → 50건 → 100건 순서로 확대한다.
한 구간이 완료되면 그 구간 전체를 개발 중에 반복 실행하지 않는다.
다만 기존 성공이 깨지지 않았는지 확인하는 소규모 보호 시험과 마지막 전체 확인은 예외로 실행한다.


2. 현재 상태와 숫자 기준

2.1 전체 재실행 결과

- 전체 입력: 1,542건
- 공식 통계 검색 전 단계에서 멈춘 주장: 571건
  · 기사 본문이 더 필요한 주장: 101건
  · 문장 분리 또는 구조 보완이 필요한 주장: 470건
- 공식 통계를 찾아볼 준비가 된 주장: 971건
- 끝까지 자동 판정된 주장: 27건
  · 기사 수치와 공식 통계가 일치: 4건
  · 기사 수치와 공식 통계가 불일치: 23건
- 전체 자동 판정률: 약 1.8%

2.2 국가통계포털 조회 규모

- 통계표 검색: 2,775회
- 통계표 항목 구조 조회: 15,149회
- 통계표 기간 구조 조회: 6,901회
- 공식값 조회 단계 도달: 96건
- 검색과 구조 조회의 확인된 요청 합계: 24,825회

96건은 공식값 조회 단계에 도달한 주장 수이며, 공식값 요청 횟수와 같은 단위가 아니다.
현재 보고서에는 공식값·발표정보의 실제 통신 횟수 합계가 따로 없으므로 24,825회에 96건을 더하지 않는다.
따라서 확인 가능한 국가통계포털 요청은 최소 24,825회이며, 공식값과 발표정보 요청까지 포함한 실제 통신 횟수는 이보다 많다.

이 숫자는 1,542건을 모두 다시 실행할 때마다 비슷한 조회 부담이 반복될 수 있다는 뜻이다.
구간 분류만으로 한 주장에 필요한 공식 조회가 없어지는 것은 아니다.
대신 수정한 구간만 다시 실행해 전체 재실행의 반복을 없앨 수 있다.

2.3 과거 목표 숫자와 현재 숫자를 섞지 않는 원칙

과거 작업 목록에는 다음 숫자가 있었다.

- 개념 확정 실패: 268건
- 국가통계포털만으로 부족할 때 공식 기관을 추가로 조회해야 했던 주장: 135건
- 정확한 공식값 위치와 필수 조건을 찾지 못한 주장: 120건
- 여러 주장 분리 필요: 641건
- 기사 문맥 필요: 539건

이 숫자는 과거 분류 기준과 당시 입력 자료에서 나온 목표 수치다.
현재 1,542건 재실행의 470건·101건과 기준이 되는 전체 수가 같지 않으므로 서로 더하거나 직접 비교하면 안 된다.

현재까지 기능 범위 검사에서는 다음이 확인됐다.

- 여러 주장 재투입 기능이 적용될 수 있는 원문: 883건
- 이 원문에서 만들 수 있는 개별 주장: 2,295건
- 기사 문맥 보강 대상 확인: 593건
- 같은 뜻 표현 목록으로 통계 개념이 연결된 주장: 1,433건
- 지표 자체가 빠져 의미를 정할 수 없는 주장: 109건
- 공식 기관 추가 조회 방법을 적용할 수 있는 주장: 152건
- 정확한 공식값 위치 찾기 보강을 적용할 수 있는 주장: 553건

이 수치는 기능이 적용될 수 있는 범위를 검사한 결과다.
모든 주장이 실제 공식 통계 판정까지 완료됐다는 뜻은 아니다.

따라서 새 기획에서는 현재 1,542건 결과를 하나의 기준으로 고정하고, 주장마다 처음 멈춘 구간을 다시 부여한다.


3. 모든 주장을 겹치지 않게 나누는 방법

아래 잠정 구간 수는 각 주장에 기록된 최종 중단 이유를 이용해 만들었다.
공식 조회 전의 571건은 ‘공식 조회 후 보류’가 아니라 문맥 보강·문장 재정리·사람 확인이 먼저 필요한 상태다.
공식 조회에 들어간 971건만 실제 공식 조회 뒤의 보류와 자동 판정으로 나뉜다.
0단계에서는 실행 기록에서 처음 멈추거나 다른 처리로 넘어간 지점과 최종 중단 이유를 주장 번호별로 대조한다.
둘이 다르면 더 앞에서 멈추거나 다른 처리로 넘어간 지점을 주된 구간으로 사용하고, 불일치 목록을 별도로 남긴다.
그 뒤 중복 0건·누락 0건을 확인해 구간 수를 확정한다.

각 주장에는 반드시 하나의 주된 구간만 부여한다.
고용·출산·물가·산업 같은 분야와 계산 종류는 보조 표시로 붙인다.

여기서 ‘원문 주장’은 최초 1,542개 문장을 뜻한다.
‘분리된 개별 주장’은 한 원문에 여러 수치가 있을 때 새로 나눈 각각의 검증 대상을 뜻한다.

3.1 주된 구간

구간 0. 이미 성공한 주장: 27건

- 목적: 앞으로의 수정으로 기존 성공이 깨지지 않도록 보호한다.
- 처리: 개선 대상이 아니라 매번 짧게 확인하는 보호용 시험 자료로 사용한다.
- 완료 기준: 27건의 공식 출처·공식값 위치·판정이 이전과 동일해야 한다.

구간 1. 공식 조회 전에 멈춘 주장: 571건

1-A. 기사 본문이 더 필요한 주장: 101건

- 문제가 되는 경우
  · ‘지난달’, ‘같은 기간’, ‘이들’처럼 앞 문장이 있어야 뜻을 알 수 있다.
  · 기사 문장만으로 지표·기간·대상을 알 수 없다.
- 개선 내용
  · 기사 제목과 대상 문장 앞뒤 문맥을 함께 읽는다.
  · 빠진 지표·기간·지역·대상을 다시 정리한다.
  · 정리된 주장을 다시 분류해 공식 조회 가능 여부를 결정한다.
- 결과
  · 공식 조회 가능하면 다음 구간으로 보낸다.
  · 기사 전체를 봐도 확정할 수 없으면 이유를 남기고 사람 확인 대상으로 보낸다.

1-B. 문장 분리 또는 구조 보완이 필요한 주장: 470건

- 먼저 다음 종류로 세분화한다.
  · 한 문장에 서로 다른 수치 주장이 여러 개 들어 있는 경우
  · 값·단위·기간 중 필요한 정보가 빠진 경우
  · ‘약’, ‘대’, ‘이상’, 범위값처럼 정확한 단일값이 아닌 경우
  · 전망·가정·조건부 표현인 경우
  · 수치 검증 대상이 아닌 정의·설명 문장인 경우
- 개선 내용
  · 여러 주장은 하나씩 나눠 각각 새로운 번호를 부여한다.
  · 나눈 주장마다 필요한 12개 정보를 다시 정리한다.
    12개 정보는 지표, 값, 단위, 대상 시점, 월·분기·연간 구분, 지역, 대상 집단, 성별·연령·산업 같은 세부 조건, 비교 방식, 계산 방식, 추가 조건, 기사에 적힌 출처 힌트다.
  · 최초 원문과 분리된 개별 주장 사이의 관계를 기록한다.
  · 분리된 각 개별 주장을 다시 분류하고 공식 통계 검증 과정에 넣는다.
- 이미 확인된 사례
  · 별도 시험에서 원문 4건을 9개의 개별 주장으로 나눴다.
  · 9건 모두 실제 공식 통계 판정까지 완료됐다.
- 남은 일
  · 이 경로를 일부 시험이 아니라 전체 해당 주장에 적용한다.

1-C. 원문과 분리된 개별 주장 수를 관리하는 방법

- 최초 원문 수는 항상 1,542건으로 고정한다.
- 원문을 나눠 만든 개별 주장 수는 별도로 집계하며 1,542건에 더하지 않는다.
- 분리된 개별 주장은 다시 분류해 구간 2부터 구간 7 가운데 처음 멈춘 곳으로 보낸다.
- 어느 단계에서도 멈추지 않고 자동 판정된 개별 주장은 ‘구간 0-S. 분리 후 성공’으로 따로 집계한다.
- 구간 0-S의 새 성공은 모두 성공 보호 후보 목록에 추가한다.
- 개발 중 매 수정마다 0-S 전체를 다시 실행하지 않는다.
- 개발 중 보호 시험은 기존 성공 27건과 0-S에서 분야·계산 종류별로 고정한 대표 자료 최대 20건을 별도로 실행한다.
- 이번 수정과 직접 관련된 0-S 주장이 대표 20건에 없으면 해당 주장을 우선 포함하고, 다른 대표 자료를 빼 전체 20건 상한을 유지한다.
- 0-S 전체는 해당 구간의 전체 실행이 끝날 때와 마지막 전체 확인 때 실행한다.
- 구간 0과 0-S는 개선 대상이 아니므로 20건·50건·100건 확대 시험을 적용하지 않는다.
- 보호 시험에서는 공식 출처·공식값 위치·판정이 유지돼야 한다.
- 한 원문에서 나온 모든 개별 주장이 자동 판정, 공식 조회 후의 올바른 보류, 공식 조회 전 사람 확인, 또는 검증 대상 제외 가운데 하나로 확정돼야 그 원문을 완료로 본다.
- 최종 보고에는 ‘원문 처리 1,542건 중 완료 수’와 분리된 개별 주장 상태별 수를 따로 적는다.
- 분리된 개별 주장 전체 수는 ‘자동 판정 수 + 공식 조회 후 보류 수 + 공식 조회 전 사람 확인 수 + 검증 대상 제외 수’와 정확히 같아야 한다.
- 따라서 원문 완료율의 기준은 1,542건이고, 개별 주장 판정 결과의 기준은 분리 후 실제 생성된 전체 개별 주장 수다.

구간 2. 통계표 검색 요청을 끝내지 못한 주장: 44건

- 문제: 국가통계포털 통계표 검색 요청이 실패하거나 정해진 시간 안에 끝나지 않았다.
- 개선 내용
  · 검색어 중복을 제거한다.
  · 같은 주장 안에서 같은 통계표가 반복 발견되면 한 번만 처리한다.
  · 실패한 요청만 정해진 횟수만큼 다시 시도한다.
  · 외부 서비스 장애이면 ‘통계 없음’으로 처리하지 않고 조회 장애로 기록한다.
- 완료 기준
  · 실행 시작과 끝에 이미 알려진 통계표를 시험 조회해 국가통계포털이 작동 중인지 확인한다.
  · 시험 조회가 성공한 상태에서는 44건이 검색 결과 또는 명확한 공식 조회 실패 결과를 가져야 한다.
  · 시험 조회도 실패하면 프로그램 판단 문제가 아니라 외부 장애 묶음으로 분리한다.

구간 3. 통계표 구조 정보를 가져오지 못한 주장: 119건

- 문제: 후보 통계표는 찾았지만 공식 항목·기간·지역 식별정보를 가져오지 못했다.
- 개선 내용
  · 항목 정보와 기간 정보 요청을 따로 기록한다.
  · 실패한 구조 정보만 다시 조회한다.
  · 구조 조회 실패와 조건에 맞는 항목이 없는 경우를 분리한다.
- 완료 기준
  · 모든 대상이 공식 항목·기간·지역 식별정보를 받거나, 실제 조회 실패 이유를 남겨야 한다.

구간 4. 필수 조건에서 탈락한 주장: 557건

4-A. 조건에 맞는 후보가 없는 주장: 302건

- 확인할 조건
  · 작성기관
  · 통계 분야와 지표
  · 지역
  · 기간과 월·분기·연간 구분
  · 성별·연령·산업·품목 등 대상
  · 값의 단위
- 개선 내용
  · 기사 표현과 공식 통계표 표현의 같은 뜻 낱말을 연결한다.
  · 고용·출산·물가·산업 순서로 반복 표현을 보강한다.
  · 공식 통계표가 제공하는 항목·기간·지역 식별정보에 없는 조건은 추정하지 않는다.
- 완료 기준
  · 사람이 미리 정답을 확인한 시험 자료에서 잘못된 후보 통과가 0건이어야 한다.
  · 공식 조건을 만족하는 시험 주장 가운데 80% 이상이 다음 단계로 넘어가야 한다.

4-B. 정확한 공식값 위치 후보가 없는 주장: 255건

- 생성된 모든 개별 주장에 자동 판정 또는 정확한 중단 상태가 있어야 한다.
- 잘못된 자동 판정은 0건이어야 한다.
- 사람이 공식 통계로 검증 가능하다고 확인한 개별 주장 가운데 분야별 80% 이상, 전체 80% 이상이 공식값·발표정보·프로그램 계산을 거쳐 자동 판정돼야 한다.
- 자동 판정되지 않은 개별 주장은 실제로 처음 멈춘 단계와 이유를 남겨야 한다.
- 자동 판정된 모든 개별 주장에는 공식값 출처, 공식값 위치, 발표 근거, 계산 결과가 남아야 한다.
- 실행 시작과 끝의 시험 조회가 성공했다면 외부 조회 비정상 종료는 0건이어야 한다.
- 구간 0과 구간 0-S의 성공 보호 자료 판정이 모두 유지돼야 한다.

8단계. 최종 전체 확인

- 모든 구간이 완료된 뒤에만 1,542건 전체를 한 번 실행한다.
- 이 실행은 개발 중 반복 실행이 아니라 최종 확인용이다.
- 최초 원문 수, 분리된 개별 주장 전체 수, 자동 판정 수, 공식 조회 후 보류 수, 공식 조회 전 사람 확인 수, 검증 대상 제외 수, 실패 단계, 공식 조회 수를 따로 최종 보고한다.


7. 국가통계포털 조회량을 관리하는 방법

7.1 실행 크기 목표

- 개발 중 한 번에 실행하는 개선 대상 묶음은 최대 100건으로 제한한다.
- 성공 보호 자료는 개선 대상 묶음과 합치지 않고 별도의 시험으로 실행한다.
- 개발 중 보호 시험은 기존 성공 27건과 0-S 대표 자료 최대 20건으로, 최대 47건이다.
- 0-S 전체 보호 시험은 구간 전체 실행 종료와 마지막 전체 확인 때만 수행한다.
- 약 93.5% 감소는 보호 자료를 제외한 개선 대상 원문 수 100건을 1,542건과 비교한 값이다.
- 1,542건 전체 실행은 모든 구간 개선이 끝난 뒤 최종 확인 때 한 번만 수행한다.

7.2 중복과 재시도 목표

- 같은 주장 안에서 같은 통계표가 여러 검색어로 반복 발견되면 구조 정보는 한 번만 조회한다.
- 같은 주장·같은 통계표의 중복 구조 조회 목표는 0건이다.
- 실패한 공식 요청만 최대 2회 다시 시도한다.
- 한 묶음에서 외부 조회 실패가 연속 3회 발생하면 실행을 멈추고 국가통계포털 장애 여부를 먼저 확인한다.
- 완료된 구간 전체를 다른 구간 수정 때문에 다시 실행하는 횟수는 0회로 한다.

7.3 측정 방법

- 각 묶음에 검색·항목 구조·기간 구조·값·발표정보 조회 횟수를 따로 기록한다.
- 개선 전 같은 구간의 주장당 평균 조회 횟수를 기준값으로 저장한다.
- 더 먼 단계까지 진행한 주장은 조회가 늘 수 있으므로, 같은 단계까지 도달한 주장끼리 비교한다.
- 같은 단계 기준 조회 횟수가 늘면 중복 검색어·중복 후보·불필요한 재시도가 있었는지 확인한다.
- 처리 시간은 외부 서비스 속도 영향을 받으므로 완료 판정의 단독 기준으로 사용하지 않는다.
- 대신 각 주장 처리 시간을 짧은 순서로 놓았을 때 가운데에 있는 시간을 함께 보고한다.

7.4 지켜야 할 원칙

- 과거 저장값으로 새로운 공식 조회를 대신하지 않는다.
- 공식 조회가 필요한 주장은 반드시 현재 국가통계포털을 직접 조회한다.
- 조회량을 줄이기 위해 애매한 후보를 억지로 하나 선택하지 않는다.

8. 성능을 판단하는 기준

8.1 정확성

- 잘못된 공식 통계표를 자동으로 선택한 건수
- 잘못된 공식값 위치를 선택한 건수
- 기사 수치와 공식값 계산 결과가 정확한지
- 애매한 주장을 억지로 자동 판정하지 않았는지

8.2 진행률

- 각 구간에서 다음 단계로 넘어간 주장 수
- 최종 자동 판정까지 도달한 주장 수
- 정확한 이유와 함께 보류된 주장 수

8.3 안정성

- 입력은 있었지만 결과가 사라진 건수
- 프로그램 비정상 종료 건수
- 외부 조회 실패를 잘못 분류한 건수
- 기존 성공 자료가 다시 실패한 건수

8.4 효율성

- 주장 한 건당 통계표 검색 횟수
- 주장 한 건당 구조 조회 횟수
- 주장 한 건당 전체 처리 시간
- 수정하지 않은 구간을 불필요하게 다시 실행한 건수


9. 구간 완료 판정표

각 구간은 다음 조건을 모두 만족해야 완료로 표시한다.

- 대상 주장 번호가 고정되어 있다.
- 문장을 나누지 않는 구간은 입력 주장 수와 결과 수가 일치한다.
- 문장을 나누는 구간은 원문이 모두 보존되고, 예상한 개별 주장 수와 실제 생성 수가 일치하며, 모든 개별 주장에 결과가 있다.
- 5.1에서 해당 구간 크기에 적용하도록 정한 시험 단계를 모두 통과했다.
- 구간 0과 0-S는 확대 시험 대신 성공 보호 시험을 모두 통과했다.
- 잘못된 자동 판정이 없다.
- 기존 성공 보호 자료가 모두 통과한다.
- 공식 조회 가능한 주장에는 실제 국가통계포털 조회 기록이 남아 있다.
- 공식 조회가 불가능한 주장에는 그 판단 근거와 사람 확인 대상으로 보낸 기록이 남아 있다.
- 공식값을 사용한 계산은 프로그램이 수행했다.
- 공식 조회 후 보류된 경우에는 실제 실패 단계와 이유가 남아 있다.
- 공식 조회 전 멈춘 경우에는 문맥 보강·문장 재정리·사람 확인 중 어느 처리로 보냈는지 남아 있다.
- 결과 파일과 실행 조건의 변경 식별정보(작성일·프로그램 변경번호·자료 변경번호)가 기록되어 있다.

11. 최종 완료 기준

- 새로운 기사에서 수치 주장을 자동으로 찾는다.
- 여러 주장이 섞인 문장은 개별 주장으로 나눈다.
- 기사 문맥이 필요한 문장은 본문을 보강해 다시 정리한다.
- 공식 조회 가능한 모든 분리된 개별 주장을 같은 검증 과정에 다시 넣는다.
- 기사 뜻과 조건에 맞는 공식 통계표·항목·지역·기간을 찾는다.
- 국가통계포털에서 공식값과 발표정보를 직접 확인한다.
- 통계청 등 공식 작성기관 자료는 정해진 추가 조회 방법으로만 사용한다.
- 계산은 공식값을 사용해 프로그램이 수행한다.
- 확실하면 일치 또는 불일치를 판정한다.
- 확실하지 않으면 억지로 고르지 않고 정확한 이유와 함께 보류한다.
- 화면·여러 건 실행·명령어 실행이 모두 같은 결과를 만든다.
- 기존 1,542건뿐 아니라 새로운 기사 시험에서도 같은 과정이 작동한다.


12. 바로 시작할 첫 작업

첫 번째 작업은 1,542건을 다시 국가통계포털에 조회하는 일이 아니다.

먼저 현재 결과 파일만 사용해 다음을 만든다.

1. 1,542건의 처음 멈춘 구간 목록
2. 571건의 문맥 필요·문장 구조 문제 세부 목록
3. 각 구간의 고용·출산·물가·산업 분류
4. 각 구간에서 먼저 시험할 대표 20건 목록
5. 기존 성공 27건과 별도 성공 사례를 묶은 보호용 시험 목록

이 목록이 완성되면 첫 개선 묶음은 ‘고용 분야의 문장 분리 필요 주장 20건’으로 시작한다.
그 뒤 같은 방식으로 출산·물가·산업을 순서대로 확대한다.
