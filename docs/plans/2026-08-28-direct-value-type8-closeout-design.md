# 직접값 8번 최종 마감 설계

## 목표

이미 완료된 230건 구조화·재분류를 반복하지 않고, 최신 230행 원장에 176건 전체 좌표 탐색과 94건 공통 규칙 재실행 결과를 Claim ID로 병합하여 8번의 최종 상태를 하나로 확정한다.

## 선택한 방식

최신 누적 원장 `CLAFACT_AUTO_8번_직접값_230건_지표구체화18재처리원장_20260828.csv`를 기준으로 사용한다. 이 원장은 Claim 구조 100건 재판정, 복구 48건 공식 재실행, 지표 구체화 18건을 순서대로 포함한다. 여기에 후속 176건 평가와 그중 94건 재실행을 덮어쓰되, 행 순서와 230개 자식 Claim ID는 바꾸지 않는다.

## 병합 계약

- 기준 원장: 230행, `자식Claim번호` 유일.
- 176 평가: 기준 원장의 정확한 부분집합.
- 94 재실행: 176 평가의 정확한 부분집합이며 가장 최신 결과이므로 우선한다.
- 공식 판정 완료는 AUTO·MATCH/MISMATCH·근거 좌표·API 출처·URL·응답 해시·조회시각·공표 VERIFIED를 모두 만족할 때만 인정한다.
- 이동·제외·사전 구조화 필요 Claim은 공식 판정 실패로 오인하지 않고 별도 최종 범주로 유지한다.
- 결과가 없는 Claim은 최신 230행 원장의 기존 상태를 보존한다.

## 최종 산출물

- 직접값 230건 최종 원장 CSV 1개.
- 상태·실패 단계·공식 판정 완료·이동·제외 건수 요약 JSON 1개.
- 수행 내용, 실제 공식 판정 수, 남은 원인과 대시보드 적용 상태를 설명하는 TXT 1개.
- 각 행에는 어떤 실행 결과가 최종값을 만들었는지 출처를 기록한다.

## 완료 기준

- 230행·230개 자식 Claim ID·누락 0·중복 0.
- 최신 94건 결과가 176건 결과보다 우선 적용됨.
- 공식 판정 완료 행의 공식 근거가 엄격 계약을 충족함.
- 대시보드와 같은 canonical pipeline에서 생성된 실행 결과만 병합됨.
- 집중 테스트와 전체 회귀 테스트 결과를 기록함.
