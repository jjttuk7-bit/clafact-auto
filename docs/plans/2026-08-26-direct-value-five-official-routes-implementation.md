# 8번 직접값 5개 공식 경로 규칙 구현 계획

1. 10건 성공 결과와 동일 패턴 미해결 7건을 고정된 입력·기준 CSV로 생성한다.
2. 실패 테스트를 먼저 작성한다.
   - 전체 취업자 표 범위 처리
   - 연령별 고용률 표 선택
   - 연령·학력별 실업률 표 선택
   - 다른 주기·지역·차원 Claim에 규칙이 잘못 적용되지 않는 음성 사례
   - 복수 문장 목표 수치의 원문 일치 및 차원 복구
3. `kosis_bindings.json`과 바인딩 적용기를 데이터 중심으로 확장한다.
4. 근거 좌표 해결기가 표 자체 모집단 범위를 인식하도록 수정한다.
5. 필요한 경우 원문에서 유일하게 확인된 목표 수치의 연령·학력만 안전하게 복구한다.
6. 관련 단위 테스트 → 전체 테스트를 실행한다.
7. 최신 코드로 7건을 실제 공식 API에 재실행한다.
8. 전후 비교 CSV와 요약 JSON/TXT를 생성하고, 공식 근거 완전성 검사를 수행한다.
9. 변경을 커밋·푸시하고 최종 누적 완료 건수를 보고한다.
