2. 어떤 변경을 통합했는가

(1) 같은 실행에서 같은 기관·통계표·구조종류를 다시 요청하면
    최초 공식 조회 결과를 실행 중에만 공유한다.

(2) KOSIS 오류 40인 호출 가능 건수 제한만 재시도한다.
    데이터가 없다는 오류나 다른 오류를 성공으로 바꾸지 않는다.

(3) 여러 Claim 작업자가 같은 실행 전용 구조정보 저장소를 사용한다.
    실행이 끝나면 임시 저장소가 없어지므로 다음 신규 실행은 공식 API를 다시 조회한다.

(4) 실행 서명에 구조정보 조회 코드와 새 실행기 버전을 포함한다.
    코드가 바뀐 뒤 과거 실행 결과를 잘못 재사용하지 않도록 한다.

(5) 증거형 HTML 체크리스트와 자체 시험도 같은 실행 브랜치에 모았다.

5. 실제 공식 API 근거와 한계

이 변경은 과거 동일한 52건 공식 API 재실행에서 다음 결과를 냈다.

- KOSIS 구조정보 조회 실패: 52건에서 0건
- 공식 좌표 확정: 22건
- 공식값·공표근거·시스템 판정 생성: 8건
- 다음 실제 병목으로 남음: 44건

이 수치는 52건이 모두 최종 판정됐다는 뜻이 아니다.
구조정보 조회 병목만 52건에서 해소됐고 44건은 좌표·의미·공표·값 조회 문제로 이동했다.
또한 이번 통합 단계에서는 381건이나 52건을 다시 공식 API로 실행하지 않았다.
